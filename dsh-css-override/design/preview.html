CSS 覆盖器 · 高保真设计稿 dsh-css-override

位置：设置 → 插件 → CSS 覆盖（与「市场 / 插件管理」同级的一个页签）。下面是可直接交互的静态稿：开关、折叠、搜索、明暗切换都能点。

  • 规则列表：每条规则 = 一段 CSS；左侧开关决定它是否注入页面。
  • 展开编辑：行内编辑器（行号 + CSS 语法高亮 + 常用片段），改完点「应用」或 Ctrl+Enter 落盘。
  • 落盘状态：右上角状态灯 —— 已落盘 / 保存中 / 离线（仅本地缓存），底部显示真实文件路径，可复制、可在文件管理器中打开。
  • 注入方式：启用中的规则按列表顺序拼成一份样式表，追加到页面 <body> 末尾 → 同优先级下覆盖应用自带样式。
