添加 MCP 服务器

模板
名称 [A-Za-z0-9_-]{1,32}，接入后工具名为 mcp__<名称>__<工具> 全局唯一；用于三层开关与项目覆盖的键。
传输
启动命令 第一个词为可执行文件，其余为参数；也可把参数拆到下方每行一个。
参数（每行一个，可留空）
环境变量
值支持 ${VAR} 环境变量引用——落盘只存引用，不明文保存密钥。
URL
请求头
Authorization: Bearer ${GITHUB_TOKEN} —— 引用语法同左（若 mcp-client 不解析 header 引用则 v1 明文保存，会标注）。
⚠ 检测到疑似明文密钥（长随机串）。建议改为 ${ENV_VAR} 引用，避免密钥明文落盘。
保存后写入 profile 配置，需重启 DSH 生效；接入后默认 deferred 折叠、可被 mcp_search 检索。
