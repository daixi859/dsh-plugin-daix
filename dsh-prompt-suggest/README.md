# dsh-prompt-suggest

输入框底部工具行的提示词建议按钮：一键生成下一条指令建议；已有草稿时润色草稿并在可编辑卡片中确认后替换。

## 功能

- **生成建议**（输入框为空时点击按钮）：基于最近一轮对话生成一行中文指令建议，直接填入输入框。
- **润色草稿**（输入框有草稿时点击按钮）：把当前草稿交给模型润色，结果先弹进可编辑卡片——`Ctrl+Enter`（或点"替换草稿"）保存替换，`Esc` / 取消丢弃不动原文。
- 默认跟随当前会话的模型；在**设置 → 提示词建议**里可以固定用某个模型、并单独选思考强度。

## 位置

- 按钮：`conversation.input.right`（composer 工具行、提交按钮前的紧凑控件区；会话内才渲染）。
- 编辑卡片：`shell.overlay`（frame 顶层）。
- 设置页：`settings.section`（DSH 设置页里的「提示词建议」分区）。

## 数据通道

client 面点击按钮后 `POST /plugins/prompt-suggest/generate`：

```json
{ "sessionId": "...", "draft": "...", "provider": "...", "model": "...", "reasoningEffort": "..." }
```

host 面流程：`sessionQuery.readSurface(sessionId)` 取最近一轮 user/assistant 文本（user 尾 1500 / assistant 尾 3000 字符）→ 组装 meta-prompt → `llm.prepareCall` + `stream` 一次辅助调用（20s 超时，建议 ≤256 tokens / 润色 ≤16384 tokens）→ 清洗 → 返回文本。草稿超过 8000 字符时直接拒绝（HTTP 413），不截断。

## 提示词设计

两个模式共用一段输出契约，它同时是清洗层的判据：只输出正文（禁前言/引号/代码围栏）、语言跟随输入、禁问句与选项、事实逐字保留。

- **suggest** 先给「该推进什么」的判据（待确认项 → 验证收尾 → 新动作），再给写法（一行、≤60 字、动词开头、不复述上一轮），并配一组正反例。没有判据时模型只能猜粒度，输出会退化成总结。
- **polish** 先判力度再动笔，分三档：信息已足 → 只润色；只表达模糊意图 → 用对话补全；本身是问句 → 改写成可执行任务。草稿已足够清楚时允许原样输出，不为改而改。对话素材只用于判断意图，不复述。
- 会话文本一律用三引号围成数据块，降低「历史文本被当成指令」的概率。

清洗层：剥代码围栏、剥包裹引号、polish 剥复述任务的引导行；suggest 取首行、超 120 字符判失败、与上一条用户消息去重；polish 长度上限取 `min(16000, max(600, 原文 × 2))`。

长度是两套规则，不要混：

| 模式 | 触发 | 提示词要求 | 清洗上限 |
|---|---|---|---|
| suggest | 输入框为空 | 一行，≤60 字 | 超 120 字符判失败 |
| polish | 输入框有草稿 | 总长控制在 `polishCap` 以内（数字直接写进提示词） | `polishCap(draft)` |

`polishCap(draft) = min(16000, max(600, 原文 × 2))` —— 600 是短草稿的扩写空间，与「原文两倍」是两个不同的量，提示词里分开说明。

草稿整段送入、**绝不静默截断**：超过 8000 字符直接报错要求分段，而不是只润色前 8000 字。但润色**结果**超过 `polishCap` 时仍会被截断（截断点上不会再加提示），这是清洗层的长度保险。

失败时按钮亮红点，悬停显示错误；详细错误写入 `~/.dsh/storages/prompt-suggest/last-error.json`。

## 设置

**设置 → 提示词建议**，两项，存在 `~/.dsh/storages/prompt-suggest/settings.json`：

| 项 | 默认 | 说明 |
|---|---|---|
| 用哪个模型 | 跟随当前会话 | 固定后按钮只用这个模型。路由优先级：设置 > 会话 > 全局默认。 |
| 思考强度 | 模型默认 | 档位由模型自己公布（DeepSeek 是 `off` / `low` / `high` / `max`）。**选中 `off` 即关闭思考**，更快、更省 token。 |

- 只影响这个按钮，不影响正常对话。
- **两个模式都使用这个档位**。选「关闭」就是真的不思考，生成建议与润色都适用。
- 生成建议的输出上限是 4096 token：建议本身 ≤120 字符只占约 120 token，其余留给思考。`maxTokens` 是上限而非计费，模型提前停下不会多花。
- 选了模型不支持的档位时不会被拒绝，而是自动退回模型默认：host 先查 `resolveModelInfo`，只有该模型确实公布了这一档才传下去。
- 模型不支持调节思考强度时，第二个下拉置灰并说明原因。
