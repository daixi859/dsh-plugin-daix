# 提示词建议

输入框旁的一键辅助：根据最近一轮对话生成下一条指令，或润色当前草稿。本 context 只关心提示词的组装与输出，不关心会话存储或模型实现。

## Language（语言）

**提示词建议（Prompt suggestion）**：
点击按钮后得到的一段文本。草稿为空时是建议（suggest），草稿非空时是润色（polish）。
_Avoid_：自动补全、智能回复

**建议模式（suggest）**：
草稿为空时生成一条新的指令，填入输入框。
_Avoid_：生成、续写

**润色模式（polish）**：
草稿非空时改写草稿，结果进入确认卡，保存后替换草稿。
_Avoid_：改写、优化

**提示词模板（Template）**：
一个模式的完整 meta-prompt，含输出规则、数据块与示例。内容带占位符，由设置页保存。
_Avoid_：提示词、system prompt

**占位符（Placeholder）**：
模板中写成 `{{name}}` 的位置，渲染时替换为素材。分为必需与可选，缺少必需占位符则拒绝保存。
_Avoid_：变量、参数

**上下文素材（Context）**：
会话中最近一轮的用户消息与代理回复，经尾截断后填入 `{{userText}}`、`{{assistantText}}`。
_Avoid_：历史、记忆

**样例素材（Sample）**：
设置页提供的固定样例草稿与对话，供预览和试跑使用，不写入会话。
_Avoid_：测试数据、mock

**预览（Preview）**：
用编辑框内容组装出完整提示词并显示，不调用模型。

**试跑（Trial）**：
用编辑框内容真实调用一次模型，结果只显示在设置页，不写入输入框，不改会话。
_Avoid_：测试生成、dry run

**草稿上限（Draft limit）**：
润色时整段草稿允许的最大字符数。超出则拒绝，不截断。

**模板上限（Template limit）**：
自定义模板允许的最大字符数。

**输出（Output）**：
模型返回的原始文本。不做清洗，只有空输出会被拒绝。
_Avoid_：结果经过清洗、解析后的结果
