# 词汇表

本仓库只有一个上下文：DSH 的便签插件。

## 便签（note）

一条用户主动收藏或自己撰写的 Markdown 正文，加上它被收藏时所在的工作区与会话的 **id**。

不以「一轮回答」为身份：同一条回答被收藏两次算同一条便签，因为去重是按正文内容判定的。

## 正文（body）

便签里那段 Markdown 原文。便签没有标题字段——界面上看到的「标题」都是正文渲染出来的。

## 归属（owner）

便签记录的 `workspaceId` / `sessionId`。只存 id，不存名字；名字在展示时向宿表现查，查不到显示「未知工作区 / 未知会话」。

## 草稿（draft）

对话输入框里还没发送的内容。插件的「发送到输入框」是**追加**到草稿末尾，不是替换，也不移动焦点。

注意与「新建便签草稿」区分：后者是插件自己的 `state.draft`，指一条还没保存的便签。

## 入口（entry）

便签的两个显示位置：**左侧菜单**（`sidebar.panellist`）与**标题栏右侧**（`conversation.session.header.utilities`，位于「展开/关闭右侧栏」按钮左侧）。偏好字段是 `settings.entryPositions`，两者可同时开启，也可一个都不选；默认两个都开。

「一个都不选」只隐藏入口，不删便签、不关收藏按钮、不注销详情页。左栏的每一行来自宿主的槽注册项，因此关闭左侧菜单位置时必须真正注销注册，不能只让组件返回 `null`（那会留下一个空按钮）。

## 浮层（hover card）

**左侧菜单**图标 hover 260ms 后向右展开的面板，列出当前工作区最近 N 条便签；离开 320ms 后收起。由 `hoverEnabled` 控制，关闭后左栏 hover 不再弹出。

## 气泡（popover）

**标题栏右侧**入口点击后向左下展开的面板。内容与浮层完全相同（同一个 `HoverCardLayer` 组件），但触发方式不同：点击展开，点击面板外部 / `Esc` / 再点同一按钮收起，指针移开不会收起。不受 `hoverEnabled` 影响。

## 弹窗（modal）

便签的预览 / 编辑居中模态（`NoteModal`）。与浮层、气泡是三个不同的面：尺寸 60vw × 60vh，点遮罩或 `Esc` 关闭，正文交给宿主的 `MarkdownText` 渲染。

## 详情页（notes panel）

`main` 插槽里 key 为 `note-tabs` 的面板，只显示便签列表。**没有**页内 tab；设置不在这一面，而在 DSH 设置页里。

## 设置（settings）

指 DSH 全局设置页里由 `settings.section` 注册的那个「便签」分区，包含四项偏好：左栏浮层条数、启用左栏悬浮框、默认视图、入口显示位置。插件不再在详情页里放设置 tab。

## 基线模块（platform module）

宿主的 `PLATFORM_MODULES` 表里预置给所有客户端插件的共享模块（React、zod、ui-primitives 等）。插件 `require()` 能解析到它们，但它们**不是**依赖，不写进 `dsh.client.external`。

## 不必混用的近义词

- 「浮层」由 hover 触发，「气泡」由点击触发，「弹窗」是模态；三者共用内容时不共用名字。
- 「删除」是立刻生效 + 5 秒撤销，不是软删除；存储里删掉就是删掉，撤销是重新插回原位置。
- 「入口」是显示位置，「收藏按钮」是回答下方的动作；关闭全部入口不影响收藏按钮。
