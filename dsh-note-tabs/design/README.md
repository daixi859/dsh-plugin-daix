# dsh-note-tabs · 高保真设计稿

便签插件：把每轮回答收藏成 Markdown 便签，按工作区分组，点击可发回输入框。

**当前阶段**：设计稿待确认。确认后才写真实插件（host 落盘 + client 三面 + locale + icon）。

打开 `mock.html` 即可交互（含明暗切换、搜索、编辑、删除撤销、发送到输入框、设置弹层）。
深链：`#notes` 详情页 · `#hover` 浮层 · `#edit` 编辑态 · `#flat` 平铺视图 · `#sheet` 设置 · `#dark` 深色。

## 数据结构（草案）

```json
{
  "version": 1,
  "notes": [
    {
      "id": "n_8fk2a1",
      "text": "## 标题\n\n正文…（Markdown 原文）",
      "workspaceId": "w_xxx",
      "sessionId": "s_xxx",
      "createdAt": "2026-11-20T13:12:00.000Z",
      "updatedAt": "2026-11-20T13:12:00.000Z"
    }
  ]
}
```

`text` 的内容哈希（去空白、小写）作为去重键，运行时计算，不落盘。

## 落点（已核对本机 DSH 0.2.x slot 目录）

| 面 | 插槽 | 备注 |
|---|---|---|
| 回答下方图标 | `conversation.chat.assistant-actions` (list, session) | owner props 只有 `messageId`，正文需按 messageId 从 chat 快照取 |
| 左侧栏入口 | `sidebar.panellist` (list, root) | 每个 id 对应 `main` 的同名 key；壳层负责按钮，label 取注册元数据 |
| 详情页 | `main` (keyed, root) | `key = dsh-note-tabs`，与 panellist id 一致 |
| hover 浮层 / 点击气泡 | `shell.overlay` (list, root) | 同一个组件；左栏 hover 延迟，标题栏点击展开 + 点外部关闭 |
| 标题栏右侧入口 | `conversation.session.header.utilities` (list, session) | order 100，位于「展开/关闭右侧栏」按钮左侧的 utilities 末端 |
| 设置页 | `settings.section` (list, root) | 四项偏好 + 实时预览；详情页不再有设置 tab |

输入框发送：`inputActions.insertText(text, inputActions.captureInsertion())`，比 `setDraft` 更符合「追加」语义且不破坏引用 chip。

## 已修正

- **便签没有标题**。此前把「正文首行」渲染成衬线加粗标题，看起来像独立字段；现在统一改为正文预览，浮层同步改为正文预览。
- **详情页列表换成卡片**：`grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))`，正文 3 行截断，底部一行放会话名 + 传送/复制/编辑/删除。
- **去掉字数与时间**：卡片底部只保留会话名（来源），不再显示「N 字」「N 分钟前」。
- **操作按钮移到底部**：~~不再 hover 才出现，常驻可点~~ → **已被 R7 推翻：默认隐去，hover / 键盘聚焦才出现**（与 R7 一致，本条作废）。
- **设置页加实时预览**：右侧一栏同时摆出便签卡与悬浮框示意，改条数/开关/默认视图立刻反映。
