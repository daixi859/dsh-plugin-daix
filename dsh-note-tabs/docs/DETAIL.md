# 便签（dsh-note-tabs）

把每轮回答收藏成 Markdown 便签，并在侧栏与独立详情页里管理它们。

## 功能

- **收藏**：每条已完成回答下方多一个书签按钮；已收藏时实心高亮，再点取消。
- **侧栏悬浮窗**：左栏「便签」图标 hover 260ms 弹出，列出**当前工作区**最近 N 条（默认 10，范围 3–30）。每行只有**正文两行**（不再带来源小字），右侧 hover 出「传送 / 复制」两个动作，底部「查看全部便签」。浮层头部右侧有一个「+」：点开就在浮层里展开 textarea 就地新建，`⌘/Ctrl + Enter` 保存、`Esc` 收起输入区。正在写的时候浮层不会因为鼠标移开而自动收起，草稿也不会丢。
- **详情页**：点图标进入。卡片网格（300px 起自动填充），正文 3 行截断，底部一行是会话名 + 传送/复制/编辑/删除（hover 才出现）；顶部搜索框、**「+ 新建便签」**与「按工作区 / 全部」分段控件。搜索无结果与「真的还没有便签」是两种不同空态，加载失败带重试。
- **弹窗（预览 / 编辑）**：点卡片正文或编辑按钮，在居中弹窗里打开（60vw × 60vh，窄窗口退化为近满宽 × 70vh）——预览用 DSH 自己的 `MarkdownText` 渲染（与对话区同一份：GFM、代码块、KaTeX、shiki 高亮），编辑用同尺寸 textarea。弹窗常驻三个动作：复制 / 编辑 / 传送到输入框；`Esc` 或点遮罩关闭。
- **新建便签**：不由回答派生，自己写一条。归属当前会话（拿不到归属时显示「未知工作区 / 未知会话」）；正文为空不提交，内容重复由 host 拒绝并提示。
- **传送到输入框**：追加到当前草稿末尾（草稿非空时空行分隔），不覆盖已有内容与引用 chip。**详情页**的发送等于「回去写」——插入成功后自动切回当前会话；**浮层**里的发送则留在原处（用户还在连看几条），只收起浮层。
- **删除**：直接删除并弹 5 秒 Toast「已删除 · 撤销」，可按原位置撤销；Toast 也可直接关闭。撤销失败（同正文已存在）会另弹一条提示。
- **设置 tab**：详情页页头下方两个 tab（「便签 / 设置」）；设置里有三项偏好（悬浮窗条数、启用悬浮框、默认视图），右侧带实时预览。不再占用 DSH 的设置页。
- **返回会话**：详情页页头左侧一个图标按钮（`aria-label` = 返回会话），回到当前 session。

## 存储

全局单文件 `~/.dsh/storages/dsh-note-tabs/notes.json`，临时文件 + rename 原子写；一个写队列串行化所有读-改-写。

```json
{
  "version": 1,
  "notes": [
    {
      "id": "n_8fk2a1",
      "text": "## 标题\n\n正文…（Markdown 原文）",
      "workspaceId": "w_xxx",
      "sessionId": "s_xxx",
      "createdAt": "2026-11-20T13:12:00.000Z",
      "updatedAt": "2026-11-20T13:12:00.000Z"
    }
  ],
  "settings": { "hoverCount": 10, "hoverEnabled": true, "defaultView": "grouped" }
}
```

- 只存回答的 Markdown 原文，不存提问、不存标题。
- 工作区与会话**只存 id**，展示时现查；查不到显示「未知工作区 / 未知会话」。
- 去重按正文内容（去空白 + 小写）判断，因此同一条回答不会收藏两次，编辑后也不会与已有便签重复。
- 文件损坏时另存 `notes.json.bak`（仅在 .bak 不存在时写一次）并以空存储继续，不丢原文件。
- 无变化的写（同值设置、保存未改动的正文、重复收藏）不落盘：`mutate()` 靠「新对象才写」，因此 `patchSettings`/`updateNote` 在同值时原样返回 store。
- 撤销删除若遇到「同正文便签已存在 / id 已存在 / 快照无 id」，返回 409 并在界面提示撤销失败，不会假装成功。

## 版面

- 页头一行：返回图标 · 标题 + 条数 · 右侧实心「新建便签」。主操作只有一个，搜索不再和它挤在同一行。
- 页签是两条下划线，选中用品牌色；内容区不再有第二条分隔线。
- 搜索框是填充底，聚焦才出现描边——视觉重量低于卡片本身。
- 分组标题是「品牌色短竖线 + 名字」，计数推到右边缘，上下不画满宽横线。
- 卡片：发丝描边、圆角 12px、无阴影；正文与底部之间一条发丝分割线。折叠态正文 3 行截断；**底部操作默认隐去，hover 或键盘聚焦才出现**，展开态常驻。整页唯一的高饱和线索是 hover 时卡片左缘那道品牌色竖线。

## 视觉

- 字体完全跟随 DSH：正文 `var(--dsw-font-family)`、代码 `var(--ds-font-family-code)`，不写死任何字体栈；两者已合成内置栈与用户在设置里选的字体。
- 字号跟随设置：正文 `calc(var(--dsh-content-font-size, 14px) * .9)`，代码/编辑框 `var(--dsh-code-font-size, 11px)`。
- 颜色只用 `--dsw-alias-*` 主题 token，明暗两套自动切换。
- 标题不再是衬线体（原本的衬线与「跟随 DSH 字体」冲突），文书感改由字重、字号与分割线承担。

## 限制

- 收藏按钮的正文来自 Chat 快照；取不到时按钮禁用（悬停提示说明原因），不会收藏空内容。
- 便签总数上限 1000 条，达到上限后收藏返回「便签数量已达上限」。
- 网络通道为包内 HTTP 路由 `POST /plugins/note-tabs/rpc`（本机 DSH 未向已安装 client bundle 暴露 `host.call` 桥）。失败时 host 返回稳定错误码 `code`（`duplicate`/`empty`/`full`/`missing`/`invalid`/`id-exists`/`unknown-op`），client 按 code 查本地化文案，不依赖中文 error 文本判断错误类型。
- 便签不做 Agent 工具，只有 UI。
- 悬浮窗定位在左栏图标右侧，随窗口高度收敛，不做手动拖拽。
